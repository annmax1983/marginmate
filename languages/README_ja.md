## なぜ VKT MarginMate か

販売者は今も手作業で計算しています。価格を控え、販売手数料の率を思い出し、サイズ帯ごとの FBA 配送料を調べ、広告費を推測し、Excel で引く。料率はマーケットプレイスとカテゴリごとに違い、Amazon の料金ページは 3 クリックと PDF 1 枚の先にあります。

VKT MarginMate は、すでに開いている商品ページのカート欄の隣に計算一式を置きます。本当に必要な数字は **「いくらで売るべきか」** です。

| 特長 | 内容 |
|------|------|
| 🧮 **リアルタイム内訳** | 販売手数料、FBA 配送料、保管料、入庫手数料、広告費、返品、原価を一行ずつ |
| 🎯 **損益分岐価格** | 利益がゼロになる価格。値引きの限界が分かります |
| 📈 **目標価格** | 「利益率 20% なら売価はいくらか」をその商品で算出 |
| 📋 **検索結果の利益** | 検索結果に利益バッジ（Pro は全件）、利益率で並べ替え可能 |
| 🌍 **16 マーケット** | ストアごとの料率と VAT に対応（US は段階式 FBA、英独は紹介料＋VAT、FBA 手入力） |
| ✏️ **数字はすべて編集可** | 原価、輸送費、関税、広告%、返品%、FBA 手数料の手入力 |
| 🔒 **ローカル設計** | アカウント不要、サーバー保存なし、ページ内容の送信なし |

## 計算方法

```
純収入     = 価格 ÷ (1 + VAT)          （税込ストアのみ）
販売手数料 = max(最低手数料, 価格 × カテゴリ料率)
FBA 配送料 = サイズと出荷重量から区分を判定
保管料     = 立方フィート × 月額料率 × 月数（10〜12 月は繁忙期料率）
広告費     = 価格 × 広告%
返品コスト = 価格 × 返品率（保守的に全額返金として計算）
原価合計   = 仕入 + 輸送費 + 関税
利益       = 純収入 − 上記すべて
```

料率はすべて [`data/fees.js`](../data/fees.js) にあります。Amazon の料率変更時に触るのはこの 1 ファイルだけです。拡張機能に同梱され、より新しいリモート版で上書きできるため、料率変更にストア審査は不要です。

> VKT MarginMate は推定ツールです。Amazon にはカテゴリ・サイズ・キャンペーンの例外があり、商品ページからは分かりません。また料率は年に数回変わります。価格を決める前に Seller Central で確認してください。

## プライバシー

- **アカウントなし、解析なし、追跡なし。** 原価と保存した商品は `chrome.storage.local` にのみ保存されます。
- 通信は 2 種類のみ：1 日 1 回の料率表更新と、Pro 有効化時のライセンス確認です。
- 権限は `storage`、`alarms`、Amazon 16 ドメインへのアクセス、および `annmax1983.com`（料率表更新・ライセンス購入）と `api.annmax1983.com`（ライセンス確認）への HTTPS アクセスです。
