## 为什么做这个

卖家算利润的流程一直是手工的：抄下售价、查佣金比例、按尺寸分段查 FBA 配送费、估一个广告占比，再回 Excel 里减一遍。费率按站点和类目不同，亚马逊自己的费用页要点三次、还要翻 PDF。

VKT MarginMate 把整套计算放到你正在看的商品页上，买盒子旁边就能看到，并且给出真正关键的那个数字：**你应该卖多少钱**。

| 特点 | 说明 |
|------|------|
| 🧮 **实时拆解** | 佣金、FBA 配送、仓储、入库配置、广告、退货、到岸成本逐行列出 |
| 🎯 **保本售价** | 利润为零的那个价格，知道能降到哪 |
| 📈 **目标利润价** | “要 20% 利润该卖多少”，当前商品直接算出来 |
| 📋 **搜索页利润** | 搜索结果带利润角标，Pro 覆盖全部结果，可按利润率排序 |
| 🌍 **16 个站点** | 按站点匹配费率并处理增值税（美国分档 FBA；英德佣金+增值税，FBA 手填） |
| ✏️ **所有数字可改** | 成本、头程、关税、广告占比、退货率、FBA 手动覆盖，按 ASIN 保存 |
| 🔒 **本地优先** | 无账号、无服务端存储、不上传页面内容 |

## 计算方式

```
净收入   = 售价 ÷ (1 + 增值税)        （仅含税站点）
平台佣金 = max(最低佣金, 售价 × 类目费率)
FBA 费   = 按尺寸 + 发货重量查分段
仓储费   = 立方英尺 × 月费率 × 月数（10–12 月按旺季费率）
广告费   = 售价 × 广告占比
退货成本 = 售价 × 退货率（保守：按全额退款）
到岸成本 = 采购成本 + 头程 + 关税
净利     = 净收入 − 以上各项
```

所有费率都在 [`data/fees.js`](../data/fees.js)，是唯一需要维护的文件，来自亚马逊公开费率表。费率表内置在扩展里，同时支持远程覆盖更新，改费率不需要重新过审。

> 只是估算工具。亚马逊还有类目、尺寸、项目与促销层面的例外，任何商品页都看不出来，而且费率一年会变好几次。定价前请以卖家后台为准。
